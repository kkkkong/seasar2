## Development

This project uses Maven as its build tool. You can build the code and run tests locally as described in CONTRIBUTING.md. The repository contains multiple modules with pom.xml files (e.g., s2-tiger/pom.xml, s2jdbc-gen/pom.xml), so running `mvn package` at the repository root will build the project.
